# 浩尘大魔王 · 个人主页

一页式中文个人主页，采用温暖、简约的作品集视觉；纯静态 HTML/CSS/JS，可直接部署到 GitHub Pages，无需构建步骤。

## 发布前建议补充

主页目前只使用已知昵称，没有代填个人履历或联系方式。建议在 `index.html` 里按需更新：

- `meta description` 和首屏介绍
- “关于我”三张卡片的文字
- 代表作品介绍、图片与链接
- 联系按钮中的 `mailto:hello@example.com`（换成自己的邮箱，或删除该按钮）
- 页面页脚信息

页面使用 Google Fonts 做字体增强；网络不可用时会自动回退到系统字体。GitHub Pages 可以直接服务仓库根目录的 `index.html`。
